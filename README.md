# Useful Commands

### Project idea:

You might know [awesome-cheatsheets repo](https://github.com/LeCoupa/awesome-cheatsheets), if not i highly recommend going there first.

This project will not be covering all available commands for every single app.
It's more like commands i find useful in my daily workflow but often i just don't remember them.
So instead of keep googling them I will store them in one place 

Feel free to contribute if you think that I'm missing something!
